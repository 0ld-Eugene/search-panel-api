# 🌌 Cosmic Pop Gallery

Интерактивное веб-приложение для поиска и просмотра высококачественных изображений. Проект сочетает в себе глубокую космическую эстетику и высокую производительность анимаций.

## ✨ Особенности

- **Интерактивный поиск:** Мгновенная загрузка фото через Unsplash API.
- **GSAP Animations:** Плавный вылет карточек с задержкой (stagger), создающий эффект "живой" ленты.
- **Умный UI:** Панель поиска в стиле "Carbon", которая адаптируется под размер экрана и скрывается при чтении контента.
- **Responsive Design:** Галерея идеально выглядит на десктопах, планшетах и смартфонах благодаря CSS Grid и динамическим соотношениям сторон.

## 🛠 Технологии

- Vanilla JavaScript (ES6+)
- Unsplash API
- GSAP (Animations)
- CSS Grid & Flexbox
- БЭМ-методология

## 🚀 Как запустить

1. Клонируйте репозиторий:
   `git clone https://github.com/your-username/cosmic-pop-gallery.git`
2. Откройте `index.html` в вашем браузере.
